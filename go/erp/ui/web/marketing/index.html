Ask Tanto, the AI agent built into ERP by Layer 8, about headcount, payables, inventory or pipeline and get answers from your real data. Salaries, national IDs, bank accounts, contact details and other sensitive fields are replaced with tokens before anything reaches the language model, and restored only in the answer shown to you.

Tanto runs every query as the person asking, with that person's permissions. It has no account, no password and no back door. Behind it is a full ERP: 256 services across finance, people, supply chain, manufacturing, sales, CRM, projects, BI, documents, compliance and lending.

Why Tanto is different

Most AI assistants send your records to the model. Tanto sends tokens.

Tanto is a participant in the ERP's built-in team chat. It answers questions with live queries against the system. It was designed so that a leaked prompt, a curious model provider or an over-eager agent never exposes what it should not.

Data never leaks to the LLM

Sensitive fields are masked by design

Every sensitive field is declared once in the data model. Before a query result reaches the model, its value and any total over it become a token such as [MASK_7QX2KD]. The model reasons over tokens; you see the real values.

Runs as you

Your permissions, not an AI superuser

Every tool call runs with the identity of the person asking, so row scope and deny rules apply exactly as they do in the app. If your session expires, the AI stops instead of retrying under another identity.

No credentials to steal

The agent is not a user

Tanto has no login, password or role. Its replies are accepted only from verified agent instances on the current turn, so no browser token can post as Tanto.

Typed text is protected too

Free text is masked by shape

Social security numbers, money amounts, emails and phone numbers that people type into the chat are tokenized before they reach the model, and so are conversation summaries.

Bounded queries

No bulk extraction

An unbounded select * is rejected. Lists are capped at 100 rows, and totals must use aggregates (count, sum, avg, min, max), which keeps record-level data out of the model.

Your model, your choice

Hosted or on-premise LLMs

Administrators configure LLM providers and profiles centrally (Anthropic, or any OpenAI-compatible endpoint, including models on your own servers), and users pick a profile per conversation. The demo runs on self-hosted open-weight models.
